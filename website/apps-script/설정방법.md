# 실제 운영 모드 설정 방법 (Google 스프레드시트 연결)

`config.js`의 `backend.url`이 비어 있으면 **체험 모드**입니다.
체험 모드에서는 투표·신청서·출석·과제가 각자의 브라우저에만 저장되어 다른 사람과 공유되지 않습니다.
아래 순서대로 한 번만 설정하면 모든 수강생의 데이터가 교수자의 Google 스프레드시트와 드라이브에 모입니다.

## 1. 스프레드시트와 스크립트 만들기
1. Google 드라이브에서 **새 스프레드시트**를 만듭니다. (예: `일본어교과교재연구 2026 수강 관리`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 위쪽 함수 선택 칸에서 `setup`을 고르고 **실행**합니다.
   - 처음 실행할 때 권한 승인 창이 나오면 본인 계정으로 허용합니다.
   - 스프레드시트에 시트 9개(투표, 수강신청, 학생명단, 출석코드, 출석, 과제제출, 공지, 자료, 포트폴리오)가 생기고,
     드라이브에 `일본어교과교재연구 — 과제 제출` 폴더가 생깁니다.
5. **관리자 비밀번호 설정:** 코드의 `setAdminPassword` 함수 안 `PASSWORD = ""`의 따옴표 안에
   관리자 비밀번호(사이트 관리자 비밀번호와 같게 권장)를 넣고 `setAdminPassword`를 실행합니다.
   실행이 끝나면 **따옴표 안의 비밀번호를 다시 지우고 저장**하세요. (해시값만 남습니다)
   관리자 화면의 명단·출석·과제·신청 내역은 이 비밀번호를 서버에서 확인한 뒤에만 보입니다.

## 2. 웹앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택에서 **웹 앱**을 고릅니다.
3. **실행 사용자: 나**, **액세스 권한: 모든 사용자**로 설정하고 배포합니다.
4. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
5. `website/config.js`의 `backend.url`에 붙여 넣습니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 3. 학기 중 교수자가 할 일
| 시트 | 할 일 |
|---|---|
| **학생명단** | 수강생의 `학번 / 이름 / 인증코드`를 입력합니다. 인증코드는 학생마다 다르게, 첫 수업에서 개별로 알려 주세요. |
| **출석코드** | 수업일마다 `날짜(2026-03-03) / 코드(예: SAKURA) / 시작(13:00) / 종료(16:15)`를 입력하고, 수업 중에 코드를 칠판에 공지합니다. 시작·종료를 비우면 그날 하루 종일 출석할 수 있습니다. |
| **출석 · 과제제출 · 수강신청 · 투표** | 자동으로 쌓입니다. 과제 파일은 드라이브 폴더에 `주차_학번_이름_파일명`으로 저장됩니다. |

## 참고
- 과제 파일은 최대 10MB까지 받을 수 있습니다. `Code.gs`의 `MAX_MB`와 `config.js`의 `upload.maxMB`를 같이 바꾸세요.
- 로그인은 6시간 동안 유지됩니다.
- 인증코드는 비밀번호처럼 쓰이므로 다른 서비스의 비밀번호를 쓰지 않도록 안내하세요.
