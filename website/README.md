# 일본어교과교재연구및지도법 강의 사이트 — 사용 안내서

고려대학교 일어일문학과 「일본어교과교재연구및지도법」 강의 소개 사이트입니다.
서버 없이 동작하는 정적 사이트이며, 사이트의 모든 내용은 `config.js` 한 파일에 모여 있습니다.

---

## 1. 폴더 구성

| 파일 | 역할 | 고칠 일 |
|---|---|---|
| `index.html` | 페이지 뼈대 | 거의 없음 |
| **`config.js`** | **사이트 내용 전체** (문구, 일정, 과제, 투표, 신청서 항목, 관리자 비밀번호 해시 등) | **여기만 고치면 됨** |
| `style.css` | 디자인 (맨 위 `:root`의 색상만 바꾸면 전체 색이 바뀜) | 선택 |
| `app.js` | 화면 그리기, 커리큘럼·달력 | 없음 |
| `participate.js` | 투표, 수강 신청서, 로그인·출석·과제 제출, 공지, 팝업, 폭죽 | 없음 |
| `admin.js` | 관리자 화면 | 없음 |
| `apps-script/` | 실제 운영용 Google Apps Script 코드와 설정 방법 | 운영 모드에서만 |

## 2. 사이트 열기

- **내 컴퓨터에서 보기:** `index.html`을 더블클릭하면 브라우저에서 바로 열립니다.
- **인터넷에 올리기:** 아래 「6. 배포 방법」을 보세요.

| AI 도구 · 준비물 · FAQ | 실습 도구 소개, 준비물, 자주 묻는 질문 |

## 4. 내용 고치기 — 두 가지 방법

### 방법 A. 관리자 화면에서 고치기 (추천)
1. 오른쪽 위 **자물쇠 아이콘**을 누르고 관리자 비밀번호를 입력합니다.
2. **사이트 편집** 탭에서 고칠 영역(첫 화면, 커리큘럼, FAQ 등)을 고르고 내용을 바꿉니다.
   항목 추가·삭제·순서 바꾸기(↑ ↓ ✕)도 할 수 있습니다.
3. **미리보기에 적용**을 누르면 *내 브라우저에서만* 바로 바뀐 모습이 보입니다.
4. **설정 파일** 탭 → **config.js 내려받기**로 받은 파일을 `website/config.js`와 바꾸고 다시 배포하면
   **모든 방문자에게** 적용됩니다.

> 정적 사이트라서 관리자 화면에서 고친 내용이 다른 사람에게 바로 전달되지는 않습니다.
> 꼭 4번처럼 파일을 바꿔 다시 올려야 합니다. (관리자 화면에서 내려받은 config.js에는 원래 파일의 설명 주석이 빠집니다.)

### 방법 B. `config.js`를 직접 고치기
메모장이나 VS Code로 `config.js`를 열어 따옴표 안의 글자를 바꿉니다. 각 항목 위에 설명이 적혀 있습니다.
- 수업 날짜는 개강일 `curriculum.startDate`가 들어 있는 주를 1주차로 하여, `curriculum.days`(예: `["월", "수"]`)의 요일마다 자동으로 잡힙니다. `holidays`에 넣은 날은 휴강으로 표시되고 주차 내용은 밀리지 않습니다.
- 과제 마감은 `"2026-03-23 23:59"` 형식으로 적습니다.
- ★ 표시가 붙은 값은 예시이니 실제 값으로 바꾸세요.

## 5. 관리자 모드

| 탭 | 할 수 있는 일 |
|---|---|
| 대시보드 | 신청·학생·오늘 출석·과제·투표·공지 수, 다음 수업, 투표 결과 |
| 사이트 편집 | 사이트 정보와 모든 영역의 내용 수정 |
| 수강생 명단 | 한 명씩 추가, 엑셀에서 복사해 한꺼번에 붙여넣기, 인증코드 자동 생성, 명단 저장·내려받기 |
| 공지사항 | 공지 올리기(중요 표시)·삭제 |
| 자료 등록 | 주차를 고르고 **Google Drive 주소**를 붙여넣어 자료실·커리큘럼에 자료 추가·삭제 |
| 포트폴리오 | 학생 작품을 **Google Drive 주소**로 등록 (제목·학생·학기·분류·소개, 공개 동의 확인 필수) |
| 출석 | 학생×주차 출석표(O/X), 출석률, **엑셀(.csv) 내려받기** |
| 과제 | 과제별 제출 목록, 미제출자, **엑셀(.csv) 내려받기** |
| 수강 신청 | 신청서 전체 목록, **엑셀(.csv) 내려받기** |
| 설정 파일 | config.js 내려받기 / JSON 백업, 파일 불러오기, 미리보기 해제, 관리자 비밀번호 변경 |

- **비밀번호:** 기본 비밀번호는 별도로 전달했습니다. **처음 들어가면 바로 바꾸세요.** (설정 파일 탭 → 비밀번호 변경 → config.js 내려받아 교체)
- **해시로 저장:** 비밀번호는 `config.js`에 그대로 적히지 않고 SHA-256 해시값만 저장됩니다.
- **5회 잠금:** 비밀번호를 5번 틀리면 30초 동안 잠깁니다.
- **CSV 파일:** 내려받은 `.csv`는 엑셀에서 바로 열리며, 한글이 깨지지 않게 저장됩니다.

### Google Drive로 자료·작품 올리기
1. 드라이브에서 파일(또는 폴더, Google 문서·슬라이드)을 오른쪽 클릭 → **공유** → 일반 액세스를 **링크가 있는 모든 사용자 · 뷰어**로 바꿉니다.
2. **링크 복사**를 누릅니다.
3. 관리자 화면 **자료 등록** 또는 **포트폴리오** 탭에 붙여넣고 올립니다.
- 공유 설정이 「제한됨」이면 학생에게 권한 요청 화면이 뜨고, 포트폴리오 미리보기 이미지도 나오지 않습니다.
- 사이트에서 삭제해도 드라이브의 원본은 지워지지 않습니다.
- 학생 작품은 반드시 본인의 공개 동의를 받은 뒤 올리세요.

## 6. 데이터 저장: 체험 모드와 운영 모드

| | 체험 모드 (기본) | 운영 모드 |
|---|---|---|
| 설정 | `config.js`의 `backend.url`이 비어 있음 | `backend.url`에 Apps Script 웹앱 주소 |
| 투표·신청서·출석·과제·공지·명단 | **각자의 브라우저에만** 저장 | 교수자의 **Google 스프레드시트**에 모임 |
| 과제 파일 | 파일 이름만 기록 | **Google 드라이브** 폴더에 저장 |
| 용도 | 사이트 시연, 기능 확인 | 실제 수업 |

운영 모드 설정은 [`apps-script/설정방법.md`](apps-script/설정방법.md)를 따라 한 번만 하면 됩니다.
운영 모드에서는 Apps Script의 `setAdminPassword` 함수로 **데이터용 관리자 비밀번호**도 설정해야 합니다.
사이트의 관리자 비밀번호와 같게 맞추는 것을 권장합니다.

## 7. 배포 방법 (인터넷에 올리기)

`website` 폴더를 통째로 올리면 됩니다. 아래 셋 중 하나를 고르세요.

### ① Netlify Drop — 가장 간단 (회원가입 후 끌어다 놓기)
1. https://app.netlify.com/drop 에 접속해 로그인합니다.
2. `website` 폴더를 브라우저 창에 끌어다 놓습니다.
3. 몇 초 뒤 `https://○○○.netlify.app` 주소가 생깁니다. 사이트 설정에서 이름을 바꿀 수 있습니다.
4. 내용을 바꿀 때는 **Deploys** 화면에 고친 `website` 폴더를 다시 끌어다 놓습니다.

### ② GitHub Pages — 무료, 수정 이력 관리
1. GitHub에 새 저장소(예: `japanese-teaching-2026`)를 만듭니다.
2. **Add file → Upload files**로 `website` 폴더 안의 파일을 모두 올립니다. (`index.html`이 저장소 맨 위에 오도록)
3. **Settings → Pages → Branch: main / (root) → Save**를 누릅니다.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/`으로 열립니다.
5. 내용을 바꿀 때는 `config.js`만 다시 올리면 됩니다.

### ③ 학교·학과 웹 서버
`website` 폴더의 파일을 웹 서버의 공개 폴더에 그대로 복사하면 됩니다. 별도 프로그램은 필요 없습니다.

> 배포 후 고친 내용이 바로 안 보이면 브라우저에서 **Ctrl+F5**(강력 새로고침)를 누르세요.

## 8. 알아 두면 좋은 점

- **보안 수준:** 관리자 비밀번호 확인은 브라우저에서 이루어지므로 *사이트 편집 화면을 숨기는 정도*의 보호입니다.
  수강생 데이터(명단·출석·과제·신청서)는 운영 모드에서 **Apps Script가 서버 쪽에서 비밀번호를 다시 확인**하므로 안전하게 보호됩니다.
- **학생 로그인:** 학번과 학생별 인증코드를 쓰는 간단한 로그인입니다. 성적처럼 민감한 정보에는 쓰지 마세요.
- **수업 시간 기준:** 체험 모드의 출석 가능 시간은 `config.js`의 수업 시간 기준이고, 운영 모드에서는 「출석코드」 시트의 시작·종료 시간 기준입니다.
- **참고 영상 링크:** 지금은 YouTube 검색 결과로 연결됩니다. 실제 영상 주소로 바꿔 주세요.
- **브라우저 데이터:** 체험 모드 데이터나 미리보기 설정은 브라우저 사용 기록을 지우면 사라집니다.
